# Chetan Raj portfolio (AI slop edition)

Intentionally over-written copy and generic AI SaaS visuals — Vite + React + TypeScript + Tailwind CSS v4.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
