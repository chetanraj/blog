# Icona icons

The static outline icons in `src/icons/icona/` are original Icona exports from
https://icona.works/ by the Icona project (https://github.com/komalverma22/Icona).
Downloaded November 2, 2026 from the site's public `/r/<name>.json` export endpoint.
The official website states "MIT licensed" and the official
`packages/icons/package.json` declares `"license": "MIT"` (repository revision
`dd9f5217720a3f459a1f5464125701eb0d51c3a2`).

Export names: arrow-left, arrow-right, check, chevron-down, copy, dice, eye,
eye-off, file, folder, github, moon, pause, play, sun.

The original SVG geometry is unchanged. The size prop accepts strings as well as
numbers to match this site's wrapper. Chevron Up is the exported Chevron Down
rotated 180 degrees. The Random control uses Icona's dice symbol. No Icona CLI,
package installation, external runtime, particle effects or animation code is
included. Existing Feather icons remain for the unavailable social-brand and
system-monitor roles, and for the matched sound-on/sound-off pair.
