# Super Visuals post covers

Artwork by Ahmed Hassan (@uihssn), shared as free backgrounds in [his post](https://x.com/uihssn/status/2117044403999285748).

Ten backgrounds come from the user's [Figma library copy](https://www.figma.com/design/4RhoL7O9ptdxwNeSlqd5Wo/Super-Visuals--Backgrounds-Library.--Copy-?node-id=1-2). They were downloaded from the original image asset URLs returned for those design nodes, not reconstructed from screenshots. Full compositions were resized to at most 2000 pixels wide and encoded as quality-90 WebP; Astro generates responsive variants.

Only this curated set is included, not the whole library. Ten backgrounds serve thirteen posts; three repeat deliberately. Assignments are explicit in `src/utils/post-cover.ts` and stay fixed when posts are reordered or added. Each header displays a centered crop without text over the art.
