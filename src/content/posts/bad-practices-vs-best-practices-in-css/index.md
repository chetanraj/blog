Using Vanilla CSS or Pre-processor

## Bad practices

1. Writing everything in one file
2. Not adding comments
3. Naming your class like this — `.i-dont-even-know-what-to-do-with-this`
4. Too much use of `!important`
5. Not understanding specificity
6. Not using any pre-processors
7. `z-index: 999999999`

## Best practices

1. Use a CSS Methodology like BEM, Inverted Triangle architecture or OOCSS
2. Use a pre-processor like LESS, Stylus or SASS
3. Break down into multiple modules placing them into different files
4. Avoid complex selectors
5. Use reset CSS
6. Adding comments

**BONUS:** Compress the CSS file before going into PROD
